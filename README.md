# Arsound

Патчи для Android-приложения SoundCloud: своё меню настроек в стиле приложения, управление телеметрией,
скачивание доступных полных треков, контроль рекламы, быстрое открытие сохранённых плейлистов и скрытие навязчивых предложений подписки.

Проект основан на [ReVanced Patches](https://gitlab.com/ReVanced/revanced-patches) и собирается
инструментами ReVanced. Это неофициальный проект, он не связан ни с ReVanced, ни с SoundCloud.

> Проверено на SoundCloud **2026.09.02-release** (versionCode 371080), arm64, Android 16.
> На других версиях патчи могут не найти нужный код, см. «Обновление под новую версию SoundCloud».

## Что умеет

| Патч | Что делает |
|---|---|
| **Settings** | Добавляет пункт «Arsound» в настройки SoundCloud (над «Справочным центром»). Экран построен из ресурсов самого SoundCloud: шрифт Söhne, цвета светлой и тёмной темы, разметка строк и переключатели. |
| **Disable telemetry** | Тумблер «Телеметрия» в настройках Arsound. По умолчанию выключена. Применяется после перезапуска приложения. |
| **Download tracks** | Пункт «Скачать файл» в меню трека и «Проверить скачивание треков» в меню альбома или плейлиста. Сначала использует авторский download, затем поток Progressive, который воспроизводит официальный клиент. Треки по подписке и preview не скачиваются. Файлы сохраняются в `Музыка/Arsound` без системного уведомления. У скачанных треков в списках появляется значок «скачано». |
| **Control playback advertisements** | Тумблер «Блокировать рекламу в плеере». Останавливает запрос и добавление аудио- и видеорекламы между треками, в том числе в начале новой очереди, не запускает рекламные SDK и скрывает рекламные плашки в плеере, ленте, библиотеке, плейлистах и профилях. |
| **Offline first playlists** | Тумблер «Сначала сохранённое». Плейлисты и альбомы открываются сразу из памяти телефона, свежая версия подгружается в фоне. Убраны все ожидания сети на экране: сервер для чужих плейлистов, синхронизация старше суток, недостающие треки (показываются те, что есть), статус подписки на автора. Если о плейлисте в памяти ничего нет, экран по-прежнему ждёт сеть. |
| **Play downloaded files** | Тумблер «Играть скачанные из файла». Треки, скачанные Arsound, играют из `Музыка/Arsound`, а не из сети. Работает для скачанных после версии с этим патчем: у старых файлов нет связи с треком. |
| **Network** | Подключается ко всем HTTP-клиентам приложения. Сейчас даёт настройку для разработчика «Имитация плохой сети» (задержка 3–40 с на запрос); дальше сюда встанут свой DNS и блокировка RU-IP. |
| **Hide subscription offers** | Тумблер «Скрывать предложения подписки»: убирает экран покупки Go и Go+ (вместе с его ошибкой «Oops… try again») и маркетинговые окна MoEngage при запуске. |
| **Change account type** | Отдельный тип аккаунта Android, чтобы мод мог войти в аккаунт, пока установлен оригинальный SoundCloud. |
| **Custom app name** | Название приложения, по умолчанию «Arsound». |
| **Change package name** | Патч из ReVanced: ставит мод рядом с оригиналом как `com.soundcloud.android.revanced`. |

Кроме того, в настройках Arsound есть:
- **«Сбросить данные SoundCloud»**: удаляет кэш, базу треков и внутренние настройки SoundCloud, но сохраняет вход в аккаунт, настройки Arsound и список скачанных треков;
- строка **«Сеть»**: IP и страна, с которыми приложение выходит в интернет. Помогает понять, работает ли VPN.

### Чего здесь нет и не будет

Патчи **не** разблокируют платные функции SoundCloud Go и Go+ (офлайн-прослушивание, треки только для подписчиков)
и **не** обходят региональные ограничения. Скачивание не выдаёт доступ к Go/Go+ или preview-трекам:
оно использует только полный Progressive-поток, уже доступный текущему аккаунту в официальном плеере.

## Структура

```
patches/                          Патчи (Kotlin)
  src/main/kotlin/app/revanced/
    patches/soundcloud/           Патчи SoundCloud
    patches/shared/misc/          Общие части ReVanced: подключение расширения, поиск ресурсов
    patches/all/misc/packagename/ Патч смены имени пакета из ReVanced
    util/                         Утилиты ReVanced для работы с байткодом
extensions/                       Код, который встраивается в приложение (Java)
  soundcloud/                     Экран Arsound, скачивание, хуки
  soundcloud/stub/                Заглушки классов SoundCloud для компиляции
  shared/                         Общая библиотека расширений ReVanced
build-and-install.cmd             Сборка, патчинг и установка одной командой
local/                            Локальные файлы, в Git не попадают (см. ниже)
```

Как устроено: **патч** (Kotlin) при сборке находит нужный метод в байткоде SoundCloud и вставляет в него вызов.
Вызов уходит в **расширение** (Java) — обычный Android-код, который добавляется в APK и делает всю работу:
рисует экраны, ходит в API, хранит настройки.

## Что нужно для сборки

- **Windows** (скрипт сборки — `.cmd`; на других системах команды те же, см. внутри скрипта).
- **JDK 21**. Скрипт по умолчанию ищет Eclipse Temurin в `C:\Program Files\Eclipse Adoptium\jdk-21.0.6.7-hotspot`,
  другой путь можно задать через переменную `JAVA_HOME`.
- **Android SDK** (достаточно `platforms;android-34` и build-tools), путь в `ANDROID_HOME`.
- **adb** и телефон с включённой отладкой по USB.
- **GitHub CLI** (`gh`), авторизованный с правом `read:packages`. Gradle-плагин ReVanced лежит в GitHub Packages,
  и без токена сборка не скачает его. Добавить право:
  ```bash
  gh auth refresh -h github.com -s read:packages
  ```
  Токен в файлах не хранится: скрипт берёт его командой `gh auth token` при каждой сборке.

### Папка `local/`

Всё, что нельзя или не нужно публиковать, лежит в `local/` (она в `.gitignore`):

```
local/
  apk/soundcloud-2026.09.02-merged.apk   APK SoundCloud (закрытое приложение, публиковать нельзя)
  tools/revanced-cli-6.0.0-all.jar       ReVanced CLI
  tools/APKEditor-*.jar                  склейка split APK
  tools/apktool_*.jar, tools/jadx/       разбор APK
  sc-revanced.keystore                   ключ подписи мода
  out/                                   готовые APK и логи
```

**Ключ подписи `local/sc-revanced.keystore` нельзя терять и нельзя публиковать.** Android ставит обновление
только поверх приложения с той же подписью. Без этого ключа новую сборку не получится поставить поверх
установленной, придётся удалять мод вместе с данными.

Инструменты:
[ReVanced CLI](https://github.com/ReVanced/revanced-cli/releases),
[APKEditor](https://github.com/REAndroid/APKEditor/releases),
[apktool](https://github.com/iBotPeaches/Apktool/releases),
[jadx](https://github.com/skylot/jadx/releases).

### Как достать APK SoundCloud

APK собирать не нужно, его берут готовым. Проще всего с телефона, где SoundCloud установлен из Google Play:

```bash
adb shell pm path com.soundcloud.android
```

Команда выведет пути к `base.apk` и `split_config.arm64_v8a.apk`. Каждый скачивается через `adb pull <путь> local/apk/2026.09.02/`.
Google Play отдаёт приложение несколькими файлами, их нужно склеить в один:

```bash
java -jar local/tools/APKEditor-1.4.9.jar m -i local/apk/2026.09.02 -o local/apk/soundcloud-2026.09.02-merged.apk
```

## Сборка и установка

```bash
build-and-install.cmd
```

Скрипт собирает патчи (`patches/build/libs/patches-0.1.0.rvp`), применяет их к APK, подписывает ключом
из `local/` и ставит на подключённый телефон. Если телефона нет, готовый APK остаётся в `local/out/`.

## Нюансы, которые стоит знать

### Сборка и ReVanced CLI

- **Порядок `-O` важен.** Опция относится к патчу, указанному прямо перед ней. Поэтому в скрипте
  `-e "Change package name"` стоит последним, а его опции идут сразу за ним. Если вставить другой `-e` между
  ними, опции тихо уйдут не туда и установка упадёт с `INSTALL_FAILED_DUPLICATE_PERMISSION`.
- **`adb install` без `--user 0`** на некоторых прошивках ставит приложение ещё и во второй профиль.
  Появляется третья копия со значком клона.
- **R8 вырезает методы, которые вызывает только SoundCloud.** Например, `invoke()` у обработчиков нажатий
  (интерфейсы Kotlin `Function0`). Правило в `extensions/proguard-rules.pro` это запрещает.
  Без него — `AbstractMethodError` при нажатии.
- В расширении уже есть стандартная библиотека Kotlin, собственные заглушки `kotlin.*` не нужны и мешают.

### Байткод SoundCloud

- Код **обфусцирован**: у классов и методов имена вроде `a`, `F`, `x`. Искать нужный метод надёжнее по строкам,
  типам параметров и именам классов, которые R8 не переименовал (`SettingsScreenKt`, `DefaultTrackingApiFactory`
  и т. п.). Имена вроде `x` или `d` могут смениться в любой версии.
- **ID ресурсов не всегда подставлены числами.** В модулях SoundCloud ресурс читается как
  `sget …/R$string;->settings_troubleshooting`, поэтому поиск по числовому ID не находит ничего.
- **Регистры выше `v15` нельзя передать в обычный `invoke-static`.** В методах с большим числом локальных
  переменных `p0` оказывается, например, `v41`. Выход — `invoke-static/range` или сохранить значение заранее
  (так сделано в хуке значка «скачано»).
- Экран настроек SoundCloud написан на **Jetpack Compose**, и сам Compose тоже обфусцирован. Поэтому пункт
  Arsound вызывает готовую Compose-функцию строки SoundCloud (`ActionListItemKt.a`), а экран Arsound сделан
  на обычных View с ресурсами SoundCloud. Он переживает обновления лучше, чем вызовы обфусцированного Compose.

### Поведение приложения

- **Вход в мод при установленном оригинале.** Android не даёт двум приложениям один тип аккаунта
  (`com.soundcloud.android.account`), поэтому без патча «Change account type» мод падает сразу после входа.
- **«Открыть с помощью: SoundCloud / Arsound».** Оба приложения открывают ссылки `soundcloud://`, поэтому
  Android спрашивает, куда их передать. Для мода выбирай Arsound.
- **«Недоступно в вашей стране», хотя в оригинале трек играет.** SoundCloud хранит правила доступа к трекам
  в своей базе на телефоне. Если мод синхронизировал библиотеку, когда сервер считал тебя в другой стране,
  блокировки остаются в кэше. Лечится кнопкой «Сбросить данные SoundCloud».
- **Белая подложка без надписи у трека** — это трек только для подписчиков, а не блокировка.
- **Экран подписки и «Oops… try again».** Экран покупки загружает цены из Google Play. Мод установлен не
  из Play, поэтому загрузка всегда падает. Патч подменяет переход на этот экран пустым прозрачным экраном.
  Если закрывать сам экран после открытия, успевает мигнуть белый фон.
- **Промо-окна при запуске** (скидки, акции) приходят от MoEngage как HTML-страницы (`InAppWebView`).
- **Скачивание.** Сначала используется `api-v2.soundcloud.com/tracks/{id}/download`. Если файла от автора
  нет, Arsound получает свежий URL `media.transcodings` с протоколом `progressive` и отдаёт его системному
  DownloadManager. HLS-плейлисты не объединяются и не сохраняются. Треки Go/Go+ и preview отсекаются до запроса stream URL.
- **Пустая пауза «Advertisement» между треками** обычно означает, что рекламный ролик не загрузился.
  Частая причина — VPN или DNS, которые блокируют рекламные домены.
- **Вход сохраняется при «Сбросить данные SoundCloud»**, потому что SoundCloud хранит токены в системном
  хранилище аккаунтов Android, вне папки приложения. Системная кнопка «Очистить данные» в настройках Android
  удаляет всё, включая вход.

## Обновление под новую версию SoundCloud

1. Достать новый APK и склеить его (см. выше).
2. Собрать и попробовать пропатчить. CLI напишет, какие патчи упали, например
   `SEVERE: "Settings" failed`, со стеком. Строка с `patches/soundcloud/...Fingerprints.kt` показывает,
   какой метод не нашёлся.
3. Открыть APK в jadx и найти, куда переехал нужный код: по строкам, по именам классов, по соседним вызовам.
   Для точной картины байткода удобно разобрать APK: `java -jar local/tools/apktool_3.0.3.jar d -r <apk>`.
4. Поправить поиск в `Fingerprints.kt` и версию в `compatibleWith(...)`, пересобрать.
5. Проверить на телефоне: лог расширения виден через `adb logcat | findstr revanced`.
