# Arsound

Мод для Android-приложения SoundCloud: без рекламы, со скачиванием треков, своей музыкой с телефона
и плейлистами, которые открываются сразу — даже без интернета.

Arsound — это набор патчей на основе [ReVanced](https://revanced.app). Это неофициальный проект, он не связан
ни с ReVanced, ни с SoundCloud.

> Проверено на SoundCloud **2026.09.02-release**, Android 16, arm64.
> С другой версией SoundCloud часть функций может не заработать.

## Что умеет

Всё настраивается в SoundCloud: **Настройки → Arsound**.

**Без лишнего**
- Нет рекламы: ни между треками, ни баннеров, ни полноэкранной при запуске.
- Нет навязчивых предложений подписки Go и Go+; вкладку Upgrade можно скрыть.
- Телеметрия выключена.
- Дубликаты в рекомендациях (перезаливы одного и того же трека) можно скрыть.

**Скачивание**
- «Скачать файл» в меню трека — в папку `Музыка/Arsound`, если трек доступен вам целиком.
- «Проверить скачивание треков» в меню плейлиста: сколько уже скачано и сколько можно скачать ещё. Уже скачанное не скачивается повторно.
- Скачанные треки играют из файла — без интернета и без трафика.
- Треки только для подписчиков и отрывки не скачиваются.

**Своя музыка**
- Импорт аудиофайлов с телефона: из меню любого плейлиста, из «Import my music» или из настроек Arsound.
- Плейлист «Импортированные» со всеми вашими файлами.
- Треки и файлы можно добавить в любой плейлист, даже чужой, — только у вас на телефоне, на сервер ничего не уходит.
- Свой порядок плейлистов в библиотеке: зажмите плейлист и перетащите.

**Плохой интернет**
- Плейлисты и альбомы открываются сразу: их содержимое заранее сохраняется текстом, без музыки и картинок.
- Если трек оборвался из-за связи, плеер сам повторит загрузку.
- Свой DNS (например, xbox-dns.ru), если провайдер мешает SoundCloud.
- Можно запретить приложению выходить в сеть с российского IP. Плашка на главном экране покажет, что происходит с сетью.
- Проверка устройства от SoundCloud не открывается сама поверх приложения — сначала спросит.

**Прочее**
- Экономия батареи: меньше фоновых запросов.
- Ставится рядом с оригинальным SoundCloud, со своей иконкой.
- Проверка обновлений Arsound.

## Как установить

Arsound не распространяет APK SoundCloud: патчи применяются к приложению, которое вы скачиваете сами,
на компьютере с помощью [ReVanced CLI](https://github.com/ReVanced/revanced-cli/releases).

Коротко:
1. Скачайте Java 21, ReVanced CLI, файл патчей `patches-*.rvp` со страницы [Releases](https://github.com/Allvoid/arsound/releases)
   и SoundCloud **2026.09.02-release**.
2. Выполните:
   ```
   java -jar revanced-cli-6.0.0-all.jar patch -bp patches-0.1.0.rvp -e "Change package name" -O "Update permissions=true" -O "Update providers=true" soundcloud.apk
   ```
3. Поставьте получившийся `soundcloud-patched.apk` на телефон и сохраните `soundcloud-patched.keystore` для обновлений.

Подробная инструкция со ссылками на всё нужное — в описании [последнего релиза](https://github.com/Allvoid/arsound/releases/latest).
Оригинальный SoundCloud удалять не нужно — Arsound ставится отдельным приложением.

Хотите собрать патчи сами или помочь с разработкой — смотрите [BUILDING.md](BUILDING.md).

## Частые вопросы

- **«Недоступно в вашей стране», хотя в оригинале трек играет.** Откройте Настройки → Arsound →
  «Сбросить данные SoundCloud». Вход в аккаунт и настройки Arsound сохранятся.
- **Android спрашивает «Открыть с помощью: SoundCloud / Arsound».** Выберите Arsound.
- **Белая подложка без названия у трека** — это трек только для подписчиков.
